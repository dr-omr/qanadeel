# موقع روضة قناديل العلم

موقع رسمي عربي باتجاه RTL مبني باستخدام Next.js وTypeScript وTailwind CSS، مخصص لعرض بيانات الصفوف والرسوم والخدمات والسياسات الخاصة بالطلبة وأولياء الأمور في سلطنة عمان.

## تعديل بيانات الروضة

كل البيانات الأساسية موجودة في ملف واحد:

```txt
src/data/school-info.ts
```

يشمل الملف أسماء الروضة، الدولة، العملة، بيانات التواصل، روابط الشعار، الصفوف، الرسوم، الخدمات، السياسات، المستندات، الشارات، والإحصائيات.

بيانات التواصل الرسمية الحالية:

```txt
الهاتف: 94734809
واتساب: 94734809
رابط واتساب الدولي: 96894734809
البريد: qanadeel@moe.om
العنوان: صحار / الجفرة
الخريطة: https://maps.app.goo.gl/QPCvabqF5GBn5o7s7?g_st=iw
الدوام: من الساعة ٦:٣٠ صباحًا إلى ١٢:٣٠ ظهرًا
```

## الهوية والشعار

تم وضع أصول الشعار في:

```txt
public/branding/logo-full.png
public/branding/logo-mark.png
src/app/icon.png
src/app/favicon.ico
```

ألوان الهوية موحدة في:

```txt
src/data/branding.ts
src/app/globals.css
```

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم فتح:

```txt
http://localhost:3000
```

إذا كان المنفذ 3000 مستخدمًا:

```bash
npm run dev -- --port 3001
```

## أوامر التحقق

```bash
npm run lint
npm run build
```

## مساعد قناديل العلم

تمت إضافة شات بوت رسمي للزوار عبر Route Handler في:

```txt
src/app/api/chat/route.ts
```

للتفعيل محليًا أو في الاستضافة، أضف القيم التالية في `.env.local` أو لوحة
بيئة النشر:

```txt
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
```

لا يتم استخدام مفتاح OpenAI داخل مكونات الواجهة، ولا يتم حفظ المحادثات افتراضيًا.
في حال عدم توفر المفتاح يظهر للزائر تنبيه لطيف للتواصل مع الإدارة عبر واتساب.

اختبار الشات يدويًا:

```txt
1. ضع OPENAI_API_KEY في .env.local.
2. ضع OPENAI_MODEL=gpt-4o-mini أو أي موديل نصي متاح.
3. أعد تشغيل السيرفر المحلي.
4. افتح /api/chat/health وتأكد من hasApiKey.
5. جرّب سؤالًا من الواجهة مثل: ما الرسوم؟
```

مسار التشخيص:

```txt
src/app/api/chat/health/route.ts
```

## الصفحات الرسمية

تم تنظيم الموقع كبنية Hybrid تشمل الصفحة الرئيسية وصفحات داخلية:

```txt
/
/about
/fees
/admission
/policies
/contact
```

كما تمت إضافة Manifest وأيقونات PWA ليعمل الموقع كتطبيق ويب قابل للإضافة على
شاشة الهاتف.

## النشر

المشروع جاهز للنشر على Vercel كمشروع Next.js. نموذج التواصل يفتح واتساب
برسالة جاهزة، والشات بوت يحتاج متغيرات OpenAI في بيئة السيرفر فقط.
